# Farm+ Hub Web (v2.0)

Современная веб- и мобильная панель управления ботами Farm+ Hub для Minecraft.
Заменяет старый PyQt6 десктопный интерфейс и позволяет контролировать ботов с любого браузера и со смартфона через Wi-Fi.

---

## 🚀 Быстрый запуск на ПК (Windows)

### 1. Требования
- Установленный **Node.js** (версия 18+ или 20+ LTS): [https://nodejs.org](https://nodejs.org)
- Ваши запущенные Minecraft боты (FarmAgent), слушающие порты `25580–25600`.

### 2. Запуск в 1 клик
Просто запустите файл **`start.bat`** двойным кликом:
- Он сам установит зависимости при первом запуске (`npm install`).
- Запустит веб-сервер и откроет TCP сокеты к вашим агентам.

### 3. Ручной запуск через терминал (CMD / PowerShell / Bash)
```bash
# 1. Установить зависимости (один раз)
npm install

# 2. Запустить сервер
npm run dev
```

После этого в консоли появится:
```
[Farm+ Hub Web] Работает на http://0.0.0.0:3000
```

## 📱 Как подключиться со смартфона (по Wi-Fi)

1. Убедитесь, что телефон и компьютер подключены к **одному Wi-Fi роутеру**.
2. На компьютере откройте командную строку (`Win + R` -> введите `cmd` -> нажмите Enter) и напишите:
   ```cmd
   ipconfig
   ```
3. Найдите строку **IPv4-адрес** (например: `192.168.1.55` или `192.168.0.12`).
4. В браузере телефона (Chrome / Safari) откройте адрес:
   ```
   http://192.168.1.55:3000
   ```
   *(замените 192.168.1.55 на ваш IPv4)*

## ⚙️ Настройки и порты (`config.json`)

В папке приложения находится файл `config.json`:
```json
{
  "mainAccount": "MyMain",
  "autoPauseAllOnDanger": false,
  "autoScanOnStart": true,
  "autoScanPortStart": 25580,
  "autoScanPortEnd": 25600,
  "host": "127.0.0.1",
  "bots": []
}
```

- **`mainAccount`**: ник вашего главного игрока в Minecraft, которому боты передают опыт.
- **`host`**: адрес, где запущены агенты (по умолчанию `127.0.0.1`).
- **`autoScanPortStart`** / **`autoScanPortEnd`**: диапазон портов для автопоиска ботов при старте.
- **`autoPauseAllOnDanger`**: экстренная остановка всех ботов при обнаружении модератора или угрозы бана.
